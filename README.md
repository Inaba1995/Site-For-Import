# Site For Import

Лендинг для NeuroStartUp на HTML/CSS/JS.

## Цель проекта
Разработать одностраничный сайт-визитку для стартапа.

## Задачи
- Сверстать адаптивный лендинг
- Добавить интерактивные элементы на JS
- Настроить формы обратной связи

## Результат
Готовый адаптивный лендинг с современным дизайном.

## Стек технологий
- HTML5, CSS3, JavaScript

## Запуск
Откройте `index.html` в браузере.
